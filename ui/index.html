Settings
Portable apps folder

Portable apps unzip into <folder>/<app>.

Preferred sources

In order. When an app you name is available from the first of these that has it, it is added from there without asking — the row still shows the source. Empty: you always choose.

Preferred type

Used for new apps when the chosen source offers that type. If it does not, you are shown the type that exists rather than switched silently.

Checksums

Off by default. A checksum is always verified when one is published, and a mismatch always stops the install. On, a file with no published checksum is not installed at all, from any source.

Advanced

Hand-edit for per-app overrides (asset pattern, install dir, installer kind/args, process name, release tag prefix).

git-updater updates

Off by default: git-updater updates itself only to stable releases. This is separate from the per-app beta setting.

Date format
Automatically

Off by default: git-updater stays on-demand. On, opening the window checks every tracked app — it never updates or installs anything automatically.

Update all

Off by default. When Update all runs, close running apps gracefully and re-open those it closed after each update completes. Apps that do not close are skipped.
