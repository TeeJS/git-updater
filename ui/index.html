Settings

Apps and display

Portable apps folder

Portable apps unzip into <folder>/<repo>.

Date format
Sort order

Off by default: the list opens in the order you last sorted it. On, every launch starts with this sort instead. You can still click a column header to re-sort while the app is open.

Filters

Off by default: the Type and Status filters go back to All every time git-updater opens. On, they come back as you left them. The search box always starts empty.

Updating

Automatically

Off by default. On, opening the window checks every tracked app — it only checks, and never updates or installs anything.

Update all

Off by default. When Update all runs, close running apps gracefully and re-open those it closed after each update completes. Apps that do not close are skipped.

Downloads MiB

Default 500 MiB: a bigger download is refused with a message. Turn the limit off for none; large files still need enough free disk space.

git-updater updates

Off by default: git-updater updates itself only to stable releases. This is separate from the per-app beta setting.

Background

At login

Off by default. On, git-updater starts when you sign in. With the tray option below it starts hidden in the tray; without it the window opens minimized to the taskbar. Windows lists it under Task Manager → Startup apps, where you can also turn it off.

Tray

Off by default: closing the window quits git-updater. On, closing it hides it to an icon in the tray (the menu bar on a Mac). Click the icon to open it, or right-click for Open, Check now and Quit. On some Linux desktops the tray icon needs an extension; start git-updater again to bring the window back.

GitHub

GitHub token

Optional. Without one GitHub allows 60 requests an hour per network; with one, 5,000. A fine-grained token with Public repositories (read-only) access and no other permissions is enough. Stored encrypted on this computer, never in config.json.

Advanced

Files

Hand-edit for per-app overrides (asset pattern, install dir, installer kind/args, process name, release tag prefix).
